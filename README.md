# linguistics-logreg-model

В памятниках древнерусской письменности слова в дательном падеже могут встречаться с двумя типами окончаний: -ови и -оу.
Параметры, влияющие на выбор окончания, четко не определены.
С помощью Generalized Linear Model Regression мы анализируем влияние нескольких характеристик слов датасета на употребление с тем или иным окончанием.

## Параметры анализа
1) исход основы на -в (да / нет);
2) личное / неличное имя;
3) собственное / нарицательное имя;
4) количество слогов в основе дательного падежа;
5) тип основы (мягкий / твёрдый конечный согласный основы)

## Результаты
Все четыре параметра, рассмотренные при анализе, являются статистически значимыми -- p < 0.01 (параметры "(не)личное имя" и "собственное/нарицательное имя" были объединены в один вследствие их влияния друг на друга).
Сильнее всего на тяготение к выбору окончания -ови влияют две характеристики леммы: 1) личное собственное имя, 2) основа НЕ на -в. Сильнее всего на тяготение к выбору окончания -оу влияет принадлежность основы леммы к твердому типу склонения, а также рост числа слогов (чем больше слогов, тем вероятнее выбор в пользу окончания -оу).
